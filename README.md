# 深海通信电缆铺设联动仿真

这是一个无第三方依赖的交互式作业仿真，用于联动船体航迹、海流、海床坡度、放缆速度与缆线张力。

## 运行

```bash
python3 -m http.server 8000
```

打开 http://localhost:8000 ，或直接用浏览器打开 `index.html`。

## 验证

```bash
npm test
```

测试覆盖悬链线几何、放缆比例对触底滞后的影响、张力/走廊/既有管线交叉预测，以及相同海况下策略差异。

## 功能

- 俯视图显示许可走廊、船体航迹、当前触底点、未来落点轨迹、既有管线和风险 ETA。
- 剖面图显示船尾到海床的悬空电缆、海床贴合、悬空段长度与关键弯曲位置。
- 调整航速、转向速率或放缆比例后，立即重新计算未来 300 秒预测。
- 风险表列出张力超限、弯曲过急、偏离走廊、管线交叉的位置、时间和处置建议。
- 可随时暂停并保存策略，随后从相同仿真节点和海况恢复比较。
- 切换为断线后，控制指令进入队列；重连时弹窗要求明确确认执行或全部放弃。
