# 深海通信电缆铺设联动仿真

一个零依赖的浏览器仿真：把**船体航迹、海流、海床坡度、放缆速度、缆线张力**实时联动，
可视化电缆从船尾悬空下放到海床贴合的连续过程；调整航速/转向/放缆比例后即时重算
未来落点与悬空段，前瞻标出张力超限、弯曲过急、偏离走廊、与既有管线交叉的位置和预计时间；
支持任意节点暂停、分叉策略在相同海况下对比，以及断线期间指令的显式确认/放弃。

## 运行

无需构建，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

或直接用 Node 跑无头测试：

```bash
node test/sim.test.mjs
```

## 模型与结构

- `js/sim/cable.js` — 缆线准静态边值积分：自海床接触点(TDP)沿弧长积分
  张力分量 (H,V)，载荷含水中自重、法向阻力（随法向相对流速）和切向阻力（放缆速度参与）；
  以水平跨度为动态输入反解 TDP 水平张力，跨度小于最小可行跨度时判定松弛。
- `js/sim/simulation.js` — 作业状态机：船体航速一阶响应 + 航向积分（可自动沿规划走廊航行，
  亦可手动转向/叠加航向偏置）、放缆与 TDP 推进的质量守恒、跨度动力学、
  海床轨迹/船舶航迹记录、走廊与即时风险判定、快照/恢复。
- `js/sim/environment.js` — 确定性海况：带海山/海沟/平缓起伏的深度场、随时间缓变的涡旋流场、
  许可走廊多边形、两条既有管线及交叉检测。
- `js/sim/hazards.js` — 前瞻“幽灵推演”：在快照副本上推进，给出各类风险的位置与预计发生时间，
  不影响当前仿真。
- `js/sim/scenarios.js` — 策略管理：任意节点暂停并分叉，新策略继承同一海况快照独立演化，
  时间轴统一推进，可并排对比。
- `js/sim/commandQueue.js` — 断线指令队列：在线立即执行，断线入队挂起，
  重连后逐条或批量“确认/放弃”。
- `js/ui/renderer.js` — 双 Canvas 视图：
  - 俯视：水深底纹、海流矢量、走廊、既有管线、已铺缆、悬空段、TDP、预测落点与风险点；
  - 剖面：沿船首向的海床剖面、悬空缆、张力/跨度读数、急弯床段标红。
- `js/main.js` — 主循环（固定物理步长 + 倍速）、控制面板、遥测、风险列表、策略列表与重连弹窗。

## 关键默认参数（SI 单位）

| 参数 | 值 |
| --- | --- |
| 缆水中单位长度重量 | 22 N/m |
| 缆径 / 法向阻力系数 / 切向阻力系数 | 0.055 m / 1.2 / 0.02 |
| 张力报警上限 | 45 kN |
| 最小允许弯曲半径 | 40 m |
| 走廊半宽 | 100 m |
| 航速 / 放缆比例范围 | 0–3 m/s / 90%–112% |
| 默认前瞻时长 | 600 s（120–900 s 可调） |

## 操作

- 滑块调整航速与放缆比例；自动模式下可叠加 5° 航向偏置，切手动后可直接给转向速率。
- “激进/保守”预设分别制造高张力风险与松弛裕度。
- 暂停后可“从此节点分叉策略”，在侧栏切换活动策略并行比较。
- “模拟断线”后调整指令仅入队；“模拟重连”弹窗中必须逐条或批量确认/放弃。
- 俯视图滚轮缩放；右上角可切换 1×/4×/16×/60× 倍速。

`node test/sim.test.mjs` 覆盖：悬链解析解对照、张力-跨度关系与松弛判定、长时步进稳定性、
自动驾驶走廊跟随、前瞻风险发现、管线交叉事件、策略分叉独立性、断线队列确认/放弃、快照一致性。
